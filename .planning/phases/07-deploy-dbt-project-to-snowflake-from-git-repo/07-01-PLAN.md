# Plan 07-01: Fix profiles.yml for Snowflake-native dbt

<objective>
Modify the dbt profiles.yml to remove hardcoded credentials (account, user, password) and use the minimal Snowflake-native format required by dbt Projects on Snowflake. This is necessary because Snowflake-native dbt handles authentication through the session context — credentials in profiles.yml are ignored and pose a security risk in a Git repo.
</objective>

<tasks>
<task id="1.1">
<title>Update profiles.yml to Snowflake-native minimal format</title>
<read_first>
- packages/dbt/profiles.yml
- packages/dbt/dbt_project.yml
- AGENTS.md
</read_first>
<action>
Replace the entire contents of `packages/dbt/profiles.yml` with:

```yaml

# EVOLV PAYMENT ANALYTICS - Snowflake-Native dbt Profile
# =============================================================================
# This profile is used for Snowflake-native dbt execution via EXECUTE DBT PROJECT.
# NOTE: No account/user/password fields - auth is handled by Snowflake session.

    dev:
      type: snowflake
      database: COCO_SDLC_HOL
      role: ATTENDEE_ROLE
```
