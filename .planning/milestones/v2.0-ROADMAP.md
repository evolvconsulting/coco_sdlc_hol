# Milestone v2.0: HOL Content

**Status:** ✅ SHIPPED 2026-03-08
**Phases:** 1-4
**Total Plans:** 9

## Overview

Complete HOL delivery package for the COCO SDLC hands-on lab. Covers all content needed to run the lab: Snowflake provisioning, participant lab guide, live Atlassian project board, and instructor facilitation reference.

## Phases

### Phase 1: Generate Hands-on Lab Setup Script

**Goal:** Produce a single consolidated idempotent SQL script (`hol_setup.sql`) that provisions a complete Snowflake HOL environment — database, schemas, RAW tables, reference data, synthetic transactions, pre-compiled dbt model DDL (staging views + intermediate/marts dynamic tables), service user, image repository, and Cortex Agent — runnable by dataops.live or pasted into a Snowflake worksheet.
**Depends on:** Phase 0
**Plans:** 3 plans

- [x] 01-01: Assemble foundation sections (ACCOUNTADMIN bootstrap, warehouse/DB/schema setup, RAW tables, reference data, synthetic transaction generation)
- [x] 01-02: Assemble dbt DDL sections (11 staging views, 6 intermediate dynamic tables, 7 marts dynamic tables from compiled output)
- [x] 01-03: Assemble final sections (service user, image repo, semantic view, Cortex Agent), merge into hol_setup.sql, human verification checkpoint

### Phase 2: Create the Hands-on Lab Instruction Guide

**Goal:** Produce a single comprehensive markdown guide (`HANDS_ON_LAB.md`) walking HOL participants through using Cortex Code across the full SDLC — from reading a Jira ticket through committing and creating a PR.
**Depends on:** Phase 1
**Plans:** 3 plans

- [x] 02-01: Write foundation sections — header, architecture overview, setup verification, Cortex Code primer
- [x] 02-02: Write Task 1 walkthrough (retry success rate metric end-to-end) and context switch
- [x] 02-03: Write Task 2 walkthrough (KPI card), wrap-up, appendix, and human verification

### Phase 3: Generate Reference Content for Jira/Confluence

**Goal:** Produce reference `.wiki` files for Jira tickets and a Confluence data dictionary page, then create the actual artifacts in Atlassian Cloud via REST API.
**Depends on:** Phase 2
**Plans:** 2 plans

- [x] 03-01: Generate Jira `.wiki` reference files (epic + 2 stories + 3 backlog) and Confluence data dictionary `.wiki` file
- [x] 03-02: Create Atlassian artifact creation script and execute with human verification

### Phase 4: Instructor Reference Sheet

**Goal:** Produce `INSTRUCTOR_GUIDE.md` — standalone instructor-facing live reference listing every participant-typed input in sequence with timing cues, "Watch for:" callouts, and "Call out to group:" notes.
**Depends on:** Phase 3
**Plans:** 1 plan

- [x] 04-01: Write INSTRUCTOR_GUIDE.md — full prompt sequence, facilitation callouts, and troubleshooting table

## Milestone Summary

**Key Decisions:**
- ASCII art diagrams chosen over Mermaid for portability in HANDS_ON_LAB.md
- All prompts framed as suggestions (not directives) — participants guided, not scripted
- Jira/Confluence MCP interactions changed to read-only with "Beyond the lab" callouts (03-02 pivot)
- Artifacts created directly via REST API rather than bash script for Atlassian (faster, no env setup required)
- Confluence data dictionary split into 6 domain pages + index (better navigation than single page)
- Section 7 (Wrap-up) omitted from INSTRUCTOR_GUIDE — no participant inputs to sequence
- Steps 4.10a/b/c/d kept as separate entries for per-verification tracking granularity
